# Hospital-SQL-Analysis

## Project Overview
This project analyzes hospital data using SQL Server.

## Dataset Used
- Database: HospitalDB
- Table: Hospital_Data$

## SQL Concepts Used
- SELECT
- GROUP BY
- AVG()
- SUM()
- COUNT()
- ORDER BY
- TOP
- HAVING query
- Subquery
- RANK()
- ROW_NUMBER()
- CASE

## Analysis Performed
- Average stay by diagnosis
- Total treatment cost by city
- Total patients by gender
- Top 5 highest treatment costs
- Department-wise total cases
- Average treatment cost by admission type
